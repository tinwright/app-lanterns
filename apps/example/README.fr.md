# Example

🇬🇧 [English](README.md) · 🇪🇸 [Español](README.es.md)

Un compteur qui fonctionne hors ligne : touchez pour compter, il se souvient où vous en étiez.

## Installation

Ouvrez-le depuis sa page du site catalogue. Pour le garder, installez-le depuis votre navigateur :

- **Chrome ou Edge :** l’icône d’installation au bout de la barre d’adresse.
- **Safari sur Mac :** Fichier → Ajouter au Dock.
- **iPhone ou iPad :** Partager → Sur l’écran d’accueil.
- **Android :** le menu ⋮ → Ajouter à l’écran d’accueil.

## Comment l’utiliser

Touchez **+** pour compter et **−** pour décompter ; **Reset** remet à zéro. Le compte reste sur
votre appareil, même appli fermée, et l’appli s’ouvre sans connexion.
