# Example

🇫🇷 [Français](README.fr.md) · 🇪🇸 [Español](README.es.md)

A tally counter that works offline: tap to count, and it remembers where you were.

## Install

Open it from its page on the catalog site. To keep it, install it from your browser:

- **Chrome or Edge:** the install icon at the end of the address bar.
- **Safari on a Mac:** File → Add to Dock.
- **iPhone or iPad:** Share → Add to Home Screen.
- **Android:** the ⋮ menu → Add to Home screen.

## How to use it

Tap **+** to count up and **−** to count down; **Reset** goes back to zero. The count stays on your
device, even with the app closed, and the app opens without a connection.
